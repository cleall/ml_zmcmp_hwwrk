Week 1 Summary:
>Machine Learning (ML) is a process of extracting patterns from data, you have
features (attributes of an object), target (attribute to find out for unseen objects)
->Supervised Machine Learning (SML) there are always labels associated with
features, the model is trained using certain features (made of observations
and features) and targets (a vector with the target information you want to predict)
The goal is to obtain a function 'g' that takes 'X' as a parameter and makes
predictions as close as possible to the targets in 'y', where: g is the model,
X the feature matrix and y the target values, obtaining g is called training
>CRISP-DM
Understanding:
Business, Do you need ML for the project?, Project goal has to be measurable.
Data, Are data sources reliable?, Do you need more data?, What data is suitable
to measure your goal?
Data preparation: Clean, format, organize, structure your data.
Modeling: Train different models, compare your results and choose the best model
Evaluate: Measure the performance of selected model, Does it accomplish your goal?
Deploy: Make it available to all users, evaluate your deployment, based on
your results decide which features are required or not, if data presents issues 
fix them
Iteration: Start simple, learn from feedback (evaluation-deployment), improve (iterate)
>Choosing and training a model
The context or nature of your goal yields the model selection, more than one
model can help accomplish your goal but only one suits what you want to accomplish
Multiple Comparisons problem (MCP): By chance any model can be 'lucky' and obtain
close predictions because all models are probabilistic. To obtain the best model
use a training and validation datasets then use a test dataset to verify if proposed
model is suitable to accomplish your goal
