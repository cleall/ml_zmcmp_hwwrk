To use Dockerfiles
    Rename one of the Dockerfiles only to "Dockerfile"
    as each file is used to answer a different Homework question

Adjustments for Q4 and Q6
    Q4 uses pipeline_v1.bin to make predictions
    Q6 uses pipeline_v2.bin to make predictions

    Make sure you adjust the content of the main.py file
    before you build the Docker image to indicate which pipeline to use

Remember that this is an uv environment so dependencies are not included
here to keep it tidy and light
