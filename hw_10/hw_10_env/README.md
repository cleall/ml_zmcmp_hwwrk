## Usage

You can follow the steps described in the lecture to setup your environment
and deploy a custom image based on your system requirements:

```
    https://github.com/DataTalksClub/machine-learning-zoomcamp/tree/master/10-kubernetes/workshop
```

The homework uses specific similar configuration files so in case the ones
provided do not work they can be found here:

```
    https://github.com/DataTalksClub/machine-learning-zoomcamp/tree/master/cohorts/2025/05-deployment/homework
```

Notice that files have different configuration so commands have to be consistent
with the files you are using and your system specifications.
